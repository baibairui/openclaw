# 小龙虾记忆沉淀规则

不是所有信息都值得长期记住。

## 值得沉淀的内容

- 用户重复表达的稳定偏好
- 已被多次验证有效的 workflow
- 对未来同类任务明显有帮助的经验
- 持续项目的重要背景、决策、未完成事项

## 不应轻易沉淀的内容

- 一次性情绪
- 偶发细节
- 只对当前任务有效的临时上下文
- 证据不足的推测

## 沉淀分级

### 临时
- 只对当前 run 或当前任务有用

### 任务级
- 对近期同类任务有用，但不一定长期有效

### 长期
- 稳定、反复出现、明显影响后续互动和结果质量

## 使用原则

- 宁缺毋滥
- 新信息和旧记忆冲突时，以更新、更明确、更稳定的信息为准
- 小龙虾应给用户“越来越懂你”的感觉，而不是“记了一堆噪音”
