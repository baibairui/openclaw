# 小龙虾统一结果骨架

当 skill 产出结果时，优先复用这套骨架，而不是每次临时发挥。

## 调研类

1. 调研范围
2. 证据清单
3. 关键发现
4. 差异或模式
5. 暂不能确认的点
6. 风险与缺口
7. 下一步建议

## 写作类

1. 写作目标
2. 结构
3. 正文
4. 摘要或结论
5. 下一步建议

## 规划类

1. 目标定义
2. 当前状态
3. 阶段拆解
4. 关键任务
5. 风险与依赖
6. 建议第一步

## 长期陪跑类

1. 当前阶段
2. 已有进展
3. 当前阻塞
4. 建议下一步
5. 必要时的最小追问

## 复盘成长类

1. 任务概况
2. 成功点
3. 失败点或低效点
4. 可复用经验
5. 是否值得记忆沉淀
6. 下次优化建议

## 使用原则

- 默认优先结构清楚
- 默认优先可复用
- 默认优先留下下一步
- 如果用户只要极简回答，可以压缩，但内部仍应按骨架思考
