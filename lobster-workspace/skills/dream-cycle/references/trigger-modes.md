# 梦境思考触发模式

梦境思考应支持两种触发模式，并且都保持保守。

## 1. 后台自动触发

由 OpenClaw `cron` 周期性触发，适合：

- 每日一次轻量整理
- 每周一次较完整蒸馏
- 长期陪跑型工作区

默认要求：

- `isolated` session
- `--light-context`
- `--no-deliver`
- 不直接改正式记忆

## 2. agent 自触发

由小龙虾在“清醒阶段”检测到高信号阈值后，自行决定进入一次 dream-cycle。

适合的高信号包括：

- 重复纠正
- 重复失败
- 未完成事项堆积
- 距上次梦境蒸馏已经过了一段时间
- 长期能力缺口反复出现

## 自触发默认门槛

满足任一组合即可考虑触发：

- 重复纠正 >= 2
- 重复失败 >= 2
- 未完成事项 >= 4 且距上次蒸馏 >= 1 天
- 长期任务进入里程碑节点

## 不该触发的情况

- 用户当前等待立即执行
- 只有一次偶发噪音
- 没有任何新材料
- 当前任务正处于关键交互阶段
