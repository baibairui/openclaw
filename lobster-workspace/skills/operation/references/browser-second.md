# 浏览器第二优先内部参考

适用时机：

- 没有合适 API
- 目标主要存在于网页中
- 页面结构足够稳定

原则：

- 网页任务优先浏览器，不优先 GUI
- 优先依赖页面结构、按钮、表单和可见状态
- 当任务可在浏览器中稳定完成时，不退化成纯视觉桌面操作
- 默认使用独立的 agent 浏览器 profile，不与用户主浏览器环境混用
- 需要长期登录态时，保留专用 profile，而不是借用用户日常 profile

当前接线：

- 默认复用 OpenClaw 自带 browser
- 通过 `scripts/browser-run.mjs` 统一进入

推荐约束：

- 如果底层执行器支持，优先提供独立 profile 目录
- profile 目录应用于 agent 自己的浏览器会话，不碰用户主工作环境
