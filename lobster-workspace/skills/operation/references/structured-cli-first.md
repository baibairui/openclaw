# 结构化 CLI 优先内部参考

适用时机：

- 已有现成 CLI
- 能稳定包装为 CLI
- 支持 `--help`、明确参数和结构化输出
- 比浏览器或 GUI 更轻、更稳

原则：

- 能走结构化 CLI 就不要降级为浏览器或 GUI
- 优先保留可重复、可脚本化、可诊断的执行路径
- 如果某个软件只能通过 GUI 完成，再进入 GUI 兜底

当前优先示例：

- `oracle`
  适合把“带上下文的外部模型求助”变成结构化 CLI 调用
- 其他已经安装到小龙虾本地前缀的命令
  路径默认是 `/workspace/.codex-runtime/home/.npm-global/bin`

推荐动作：

- 先跑 `tool --help`
- 再跑真正命令
- 能拿 JSON 或明确结构化输出时，优先解析结构化结果

对 `oracle` 的默认理解：

- 它不是浏览器兜底，而是高质量结构化 CLI 外援
- 更适合“长问题 + 文件上下文 + 外部模型辅助判断”
- 输出属于建议性结果，后续仍应结合本地证据复核
